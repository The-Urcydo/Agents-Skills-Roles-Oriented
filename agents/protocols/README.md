# Protocols

Rules between roles, not procedures for one task. The planned set:

- **Handoff:** what a fresh session needs to continue.
- **Review:** independence, findings, and verdicts.
- **Escalation:** when to ask the human, and how to ask.
- **Definition of done:** the evidence required before work counts as finished.

Protocols arrive in Batch 4. They are host-agnostic: the host repository supplies its work tracker and paths.
