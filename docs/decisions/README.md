# Decisions

Short architecture decision records for this repository. One file per decision, named `NNNN-kebab-title.md`.

- Statuses: `proposed`, `accepted`, `rejected`, `deprecated`, `superseded`.
- Accepted decisions are binding. To reverse one, add a new ADR that supersedes it; do not rewrite the accepted outcome.
- Significant, costly, or irreversible decisions need the owner's approval in a pull request.
- Small reversible choices belong in the pull request, not here.

The checker validates the file name, front matter, status, date, and unique number.
